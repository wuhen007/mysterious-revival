# 鬼域求生

《鬼域求生》是一款运行于 AstrBot 的中文文字冒险游戏。玩家接受总部招募，组建驭鬼队伍，在灵异事件中探索地点、调查线索、发现并利用鬼的规律，逐步推进主线剧情。

> 当前为 2.0 开发版（插件元数据版本 `2.0.0.dev1`）。

## 玩法概览

- **15 章主线与 11 个可选副本**：从七中学校一路推进到终局；已解锁的势力副本也可游玩。
- **单人与团队副本**：私聊适合单人游玩；团队副本在群聊中组队，支持 2–4 人。
- **探索与战斗**：前进、调查、交谈、选择剧情分支，并指挥驭鬼行动。
- **规律与反制**：观察鬼的线索，逐步发现其杀人规律，再选择合适的鬼、技能或道具应对。
- **长线成长**：永久驭鬼、编队、图鉴、魂晶、难度解锁、复苏与结局进度保存在玩家档案中。
- **版本化内容包**：章节内容按版本加载，进行中的副本固定使用开局时的内容版本。

## 支持环境

- AstrBot：`>=4.16,<5`
- QQ 官方机器人、QQ 官方 Webhook，以及通过 `aiocqhttp` 接入的 OneBot 11。
- 仓库根目录包含插件入口 `main.py` 和 `metadata.yaml`；将仓库作为 AstrBot 插件加载即可。

不同适配器的交互展示可能不同。官方 QQ 原生指令按钮点击后会把指令填入输入框，玩家仍需手动发送；OneBot 11 等文本交互会显示可复制的指令。

## 快速开始

私聊单人游玩：

```text
/鬼域 开始
/鬼域 章节
/鬼域 开局 七中学校 单人 普通
```

开始副本后，跟随机器人返回的提示，使用 `/鬼域 前进` 探索、`/鬼域 调查` 收集线索。战斗中先留意敌鬼规律，再使用 `观察`、`指挥`、`使用` 等操作。到达撤离点并完成本章目标后，发送 `/鬼域 撤离` 结算。

新手完整流程、战斗示例和团队开局说明见 **[新手游玩指南](docs/新手游玩指南.md)**。也可在游戏内发送 `/鬼域 帮助` 查看当前指令。

## 仓库结构

- `main.py`、`metadata.yaml`：AstrBot 插件入口与元数据
- `handlers/`：命令和按钮入口
- `engine/`：战斗、剧情、成长、复苏等规则引擎
- `modes/`、`storage/`：单人/团队副本与档案存储
- `content/packs/`：按版本组织的章节、鬼怪、道具和剧情内容
- `tools/`：内容生成、校验及模拟工具
