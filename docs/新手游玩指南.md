# 鬼域求生：新手游玩指南

这份指南根据本地 WebChat 从新建合成档案推进到主线 **15/15**、达成「第四种存在」的全路径实机过程整理。它提供一条容易上手的游玩顺序；具体遭遇、线索与剧情反馈会因章节和选择而异。

## 一、先建档，再从第一章开始

私聊单人流程：

```text
/鬼域 帮助
/鬼域 开始
/鬼域 章节
/鬼域 开局 七中学校 单人 普通
```

- `/鬼域 开始`：接受招募，建立个人档案并获得初始驭鬼。每个 QQ/OneBot 用户身份有自己的档案。
- `/鬼域 章节`：查看已通关、可进入章节和可选副本。
- 新手建议先打**普通难度单人**，熟悉探索、战斗和剧情选择后，再尝试困难或团队副本。
- 私聊支持单人游玩；团队副本需要在群聊中开局。

开局成功后，机器人会说明当前地点和推荐操作。优先照着回复里的按钮或指令继续，不用一次记住全部命令。

## 二、每个地点的基本循环

1. **前进**：`/鬼域 前进`，沿当前章节路线移动；进入遭遇地点时可能立即触发战斗。
2. **调查**：`/鬼域 调查`，收集当前位置线索。看到“暂时没有新的线索”时，可以继续前进。
3. **检查状态**：用 `/鬼域 状态` 查看本局位置和状态；用 `/鬼域 背包` 查看本局补给。
4. **与人物交谈**：`/鬼域 交谈 <人物名>`，阅读剧情并选择选项。选择通常会记录在本局剧情中；先看清选项再决定。
5. **抵达出口后结算**：按章节提示完成目标，到达撤离点后发送 `/鬼域 撤离`。

章节目标各不相同。若撤离提示目标尚未完成，先按提示查看缺少的目标，并在当前阶段补足可完成的线索或剧情步骤，再撤离。

## 三、战斗入门：先观察，再行动

进入战斗后先看清：当前轮到哪只驭鬼、敌鬼是谁、还缺哪些线索。建议新手先对主要敌人使用：

```text
/鬼域 观察 敲门鬼
```

如果回复仍显示待调查线索，可在后续轮次继续观察。实机流程中，敲门鬼的线索逐步揭示了第三次敲门会发动强攻；发现规律后，战斗提示会列出已知规律和可选操作。

常用战斗指令示例：

```text
/鬼域 指挥 1 攻击 敲门鬼
/鬼域 指挥 1 技能 sick_grasp 敲门鬼
/鬼域 使用 符水 玩家
/鬼域 护主
/鬼域 跳过
```

- `1` 是当前编队槽位；按回复提示替换成当前行动驭鬼的槽位。
- 技能 ID 和敌人名字以机器人给出的操作提示为准；可直接复制完整命令，避免拼错。
- 观察、攻击、用技能和道具都会推进战斗。观察时敌鬼也可能行动；线索已经齐全、规律已经发现时，及时利用规则，不必无目的反复观察。
- 道具效果因道具而异。实机流程中，符水可恢复玩家 HP；鬼烛可让目标停顿并增加其受击伤害；黄金制品可封印敌鬼。使用前看背包与本次副本提示，留意目标类型和剩余数量。
- 捕获是可选操作，不是每章通关的必要步骤。若要尝试，使用 `/鬼域 捕获 <鬼名> [坟土|棺材钉]`；成功撤离后，本局捕获的鬼会按结算规则入档。
- 战斗中 `/鬼域 撤退` 是尝试脱离战斗；到达章节出口后 `/鬼域 撤离` 才是安全结算。两者不要混淆。

## 四、七中学校：推荐的新手练习局

首局建议按这个节奏熟悉核心循环：

1. `/鬼域 前进` 到走廊，收到线索后发送 `/鬼域 调查`。
2. 再次前进进入教室遭遇。先观察敲门鬼，再按当前轮次使用驭鬼技能攻击。
3. 战斗结束后，在教室与“留在教室的人”交谈。实机路线选择了“带他去操场出口”；剧情选项可能影响后续文本或奖励。
4. 按回复继续前进，抵达操场出口并发送 `/鬼域 撤离`。
5. 撤离后用 `/鬼域 章节` 确认新章节解锁，用 `/鬼域 存档` 查看永久档案。

## 六、行动次数与长期养成

- 每日行动次数有限，并随驭鬼数量成长；行动次数按本地日期重置。实机中三只驭鬼的档案显示 **18 次/日**。高频推进时先处理关键线索和剧情，避免在已知规律后重复试探。
- `/鬼域 存档` 可查看代号、魂晶、永久驭鬼、图鉴、通关进度和结局。
- `/鬼域 图鉴 [驭鬼名|规律ID]` 可回看已发现规律；`/鬼域 委托` 可查看当前可用难度和委托信息。
- `/鬼域 编队` 查看或调整下一局队伍；`/鬼域 商店`、`/鬼域 购买 槽位` 用魂晶扩展编队槽位。
- 难度、复苏、死机和寿命属于进阶成长机制。新手先熟悉普通难度和安全撤离，再决定是否尝试。

## 七、团队副本

团队副本只在群聊中使用，建议熟悉单人流程后再组队。基本流程是队长开团队副本，队友用邀请码加入、选择各自出战驭鬼并准备，最后由队长开始任务。机器人会提示当前大厅和可执行操作；团队共享地点、敌情和线索，但各队员的个人状态与补给分别管理。

## 八、平台交互提示

- **QQ 官方机器人**：点击原生指令按钮后，指令会填入输入框；玩家还需手动发送，按钮本身不会直接完成游戏操作。
- **OneBot 11 / 文本交互**：根据回复复制指令并发送。
- 遇到不确定的选项、槽位或技能名称，优先复制机器人当前回复中的完整命令。
